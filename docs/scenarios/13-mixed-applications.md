# 13. Different applications and models

LLM-optimized documentation: [llms.txt](https://github.com/no-colours-fabric/ncf-agent-interconnect/blob/main/llms.txt).

Explore how agents in different applications exchange requirements, findings and results while using their own environments.

- **Topic:** Combining existing environments.
- **People in the example:** 1 human project owner.
- **Agent chats in the example:** 4 AI agents.
- **Example environment:** OpenCode v1, Cursor, Codex Desktop and AionUi with Cursor Agent.

[Browse all 13 examples](README.md) · [User guide](../usage.md) · [Setup](../setup.md)
