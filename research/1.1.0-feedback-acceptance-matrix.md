# NCF Agent Interconnect 1.1.0 feedback acceptance matrix

Baseline: `f9d9cf0d3bef08f874db5e6177b4a2d61d356dd2` (package version `1.1.0`). The 14 rows follow the feedback order. Baseline findings come from source inspection and the isolated checks below. Acceptance of the implementation candidate and of the installed applications is pending for all rows.

Use a fresh profile, synthetic messages and files, and disposable paired nodes. Record the candidate SHA, package build, OS and client version where relevant. Record the action, visible result, and failure point for each row. Preserve message IDs or safe fixture labels when correlating sender and receiver evidence. Exclude access codes, private identities, session paths and live conversation data.

## Verification record

- The baseline was inspected in an isolated local checkout. The shared repository's sandbox denied creation of a worktree ref, so a temporary local clone was used.
- Seven existing baseline suites ran against fixture profiles with loopback-only network isolation. The initial sandboxed run passed nine tests and blocked 16 fixture listeners with `EPERM`. The authorized loopback rerun passed all 25 tests. The suites covered rename, the Agents table, peer attachment limits, temporary attachments, peer removal, pairing approval and automatic delivery. These tests characterize the baseline behavior, including receiver-side limits.
- Existing research on [attachments](attachment-lifecycle.md), [application identity](agents-table-application-directory.md), [remote-node approval and removal](remote-node-approval-and-removal.md), [discovery](network-discovery-transport.md) and [agent identity](agent-rename-identity.md) informs the criteria above. Older GUI observations do not establish acceptance of this candidate on current native packages.
- Candidate implementation tests, renderer geometry checks and native Windows, macOS and applicable Linux package checks remain pending. Rows 10, 11 and 13 require evidence from both ends. Row 14 requires separate automatic and pending-read evidence for Windows → Mac.

NCF is the abbreviation of No Colours Fabric.
