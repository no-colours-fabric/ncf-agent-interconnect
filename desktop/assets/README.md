# Application icon

LLM-optimized documentation: [llms.txt](../../llms.txt).

`app-icon.png`, `app-icon.icns`, and `app-icon.ico` are the checked-in application
icon exports. `scripts/build-assets.mjs` copies them without modification. The
macOS monochrome menu-bar template is generated separately.

The raster artwork was generated with the built-in image generation tool from
the owner's sketch. The source master is 1254 x 1254 pixels; the PNG export is
1024 x 1024. Its generated alpha was preserved during format conversion.
