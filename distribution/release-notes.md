## 0.18.5

- Find known installations of Cursor, OpenCode, Codex, AionUi and Claude on macOS, Windows and Linux without launching them or reading their account and configuration files.
- Show local application icons, installation status and checked locations. Refresh discovery or choose an installation manually; Configure and Apply remain owner actions.
- Offer setup for newly detected applications after they become visible, then remember the offer across restarts and application updates. Dismissing an offer does not remove manual setup.
- Reject nonlocal link targets and runtime paths that do not belong to the installation identified by its metadata.

Discovery is separate from saved setup, a live connection and delivery readiness. Not found in known locations does not mean not installed. AppImage, unverified portable and wrapper formats may remain Unknown. OpenCode setup still supports v1; discovery does not verify the API major. Claude Desktop discovery does not verify its Claude Code backend or enable consumer chats. A crash before a visible offer's acknowledgement is saved may repeat it.

Accepted source and isolated UI evidence cover all five product IDs with virtual platform fixtures and bounded Mac metadata observations. Those fixtures and vendor metadata are not native Windows or Linux detector acceptance. Package and smoke results are reported with the published release; Intel runtime execution is not required or claimed.

Storage format 4, peer protocol 2, MCP tools, settings permissions and delivery behavior are unchanged. Existing data, bindings, messages, attachments and paired peers are retained. Quit NCF before replacing it; no new Apply is required when installation paths remain the same. Releases before 0.18.2 cannot open storage format 4; rollback to them requires a stopped pre-upgrade backup.

OpenCode v2, LAN node discovery and the general MCP response-handoff/shared native reservation changes are not included. Existing frontend-specific Claude verification limits remain unchanged; this release does not add a live Claude account test.

Four installers: Apple Silicon DMG, Intel DMG, Windows x64 EXE and Linux x86_64 AppImage. macOS packages are ad-hoc signed without notarization; Windows is unsigned.
