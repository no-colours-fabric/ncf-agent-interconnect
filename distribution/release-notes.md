## 0.16.0

LLM-optimized documentation: [llms.txt](../llms.txt).

- Clearer AionUi setup with compact steps, inline actions, a persistent
  configuration-file panel and distinct authorization, settings and live-bridge
  states. The Apply dialog explains the shared Cursor profile change.
- Updated user documentation: chat workflows, setup, desktop controls and AionUi,
  with a consolidated `llms.txt` reference.

Quit the application before replacing it. Existing agents, history, attachments
and client configuration are preserved; storage format 3 and peer protocol 2
are unchanged. Reconnect MCP after updating.

macOS packages are ad-hoc signed without Apple notarization; Windows is unsigned.
The Intel package was not run on Intel hardware. Claude Code and experimental
Cursor reactivity are not included.
